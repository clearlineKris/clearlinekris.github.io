# RegMatrix

Unified compliance intelligence layer — across states, statutes, and enforcement behavior — built for operators who need more than a rulebook.

## What It Covers

- **Statutory intelligence** — regulatory frameworks, rulemaking calendars, enforcement patterns per state
- **Penumbrant analysis** — gray-zone mapping where the law is ambiguous or silent
- **Reg & Pol playbooks** — policy rationale, legislative history, stakeholder maps
- **Context Maps** — customizable situational-awareness layers (timeline, politics, economics, enforcement posture)
- **WCE field operations** — step-by-step protocols for METRC workflows, transport, compliance checks

## Document Types

| Type | Purpose |
|---|---|
| **LOTL Stacks** | Single-source-of-truth regulatory bible per state (now internal reference — RegBibles are canonical) |
| **RegBibles** | Statutory authority: every requirement traced to citation |
| **Penumbrant Pages** | Single-page quick-reference per jurisdiction |
| **Penumbrant Papers** | Full-length multi-zone analysis with decision trees |
| **Penumbrant Flavors** | Variant analysis (medical/rec/hemp/tribal) |
| **Context Maps** | Customizable client-scoped situational awareness |
| **WCE** | Field diagnostics and operational protocols |
